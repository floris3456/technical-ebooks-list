# Recommendation and evidence
Recommend to intermediate programmers who know recursion: study interpreter construction, abstract syntax and type judgments. The author PDF's implementation plan (printed p9), abstract syntax (p22) and judgments/errors (pp117–118) were inspected, not the whole book. This is language theory, rather than learning a production API. Distinct from Nystrom's Java/C interpreter/VM construction. Current Tree-sitter/OCaml manuals confirm continued application of these concepts, not endorsement.
